# 🍽️ AW's Kitchen RAG Ordering Agent

An AI-powered WhatsApp restaurant ordering system that uses Retrieval-Augmented Generation (RAG) to answer customer questions, recommend meals, process food orders, and automate restaurant operations.

## Features

- WhatsApp Ordering Assistant
- AI Agent with Tool Calling
- Retrieval-Augmented Generation (RAG)
- Menu Knowledge Base
- Google Drive Knowledge Storage
- Google Sheets Integration
- Customer Memory
- Order Processing
- Dynamic Menu Search
- Error Handling Workflow
- Automated Notifications

- Google Drive
- Google Sheets
- Vector Embeddings
- RAG
- AI Agents

---

## System Workflow

1. Customer sends a WhatsApp message.
2. AI Agent understands the request.
3. Relevant menu information is retrieved using RAG.
4. AI answers questions about meals.
5. Customer places an order.
6. Order details are stored.
7. Restaurant receives the order.
8. Customer receives confirmation.
